# FilmTrace Downloads

macOS 選單列原始拍攝設定檢視器，支援 Fujifilm、Canon、Nikon、Panasonic、Sony。

[下載 FilmTrace 0.2.1 預覽版](https://github.com/james1239090/FilmTrace-Downloads/releases/tag/v0.2.1)

macOS 13 或以上，Intel / Apple Silicon 通用。開啟 DMG 後將 FilmTrace.app 拖入 Applications。

**這是未經 Apple Developer ID 簽章／公證的預覽版。** macOS 可能阻止開啟；確認下載來源後，可在系統設定 → 隱私權與安全性允許開啟。Sparkle 更新包有獨立 Ed25519 簽章，但這不代表 Apple 公證。

在 Finder 選取單張照片、用預覽程式開啟照片，或在 Photos 選取照片後，FilmTrace 顯示檔案記錄的原始拍攝設定。首次使用所需權限由 macOS 詢問。缺少的相機設定顯示 —。

一般設定 → 軟體更新提供「檢查更新」與自動檢查開關。此預覽版 feed 會提供之後的預覽版與正式版。檢查更新會連線 GitHub，不上傳照片、檔名或 metadata，不啟用 Sparkle 系統資料回傳。

本專案只存放安裝包、更新資訊與說明；原始碼保存在私人專案。
